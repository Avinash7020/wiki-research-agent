# wiki-research-agent

Small Wikipedia research CLI built with the OpenAI SDK.

## Setup

1. Install dependencies with `python3 -m pip install -r requirements.txt`.
2. Set `OPENAI_API_KEY` in your environment.
3. Optionally set `OPENAI_MODEL` if you want to override the default `gpt-5.5`.

## Run

```bash
python3 -m src.app.main
```
